## Known reconciliation gaps

- Announcements: `/{locale}/announcements` exists, but it renders `ConsumerRoutePlaceholder`; localized document, empty behavior, and account return are not terminal.
- Scanner: `/{locale}/books/scan` exists, but it renders `ConsumerRoutePlaceholder`; camera permission, ISBN capture, and manual fallback are not implemented.
- Book-list tabs: `/{locale}/book-list` delegates to `LibraryClient`, whose reading/review/records tabs do not satisfy the frozen planned/reading/completed/will_retry status-tab contract.
- History and scan query state: the book-detail page loads progress history but does not consume `tab=history` or `scan=1`; both deep-link destinations remain non-terminal.
- Backend: provider consent, `user_consents` enforcement, AI budget/hard-cap/rate/concurrency/model controls, and the target/main dependency decision remain Todo 4 work and are not promoted by this map.
- Policy: `.agents/**` and `.omo/evidence/bookgolas-web-completion/**` remain outside the current Web allow-list, and governance active version `1.0.0` conflicts with the Web `1.1.0` release line. Commit and promotion remain blocked pending policy-owner authorization.
- Environment: hosted push delivery, real camera/OCR permission behavior, Web Share/clipboard permission behavior, provider credentials, and cross-browser hosted evidence remain unverified. Registration or source presence does not close those boundaries.

## Terminal interpretation

- `partial` and `planned` are non-terminal.
- `implemented-evidence-backed` records direct local fixture contract and browser evidence, but is non-terminal until release-level hosted evidence exists; it does not claim production parity.
- `disabled` is terminal only while billing/purchase activation remains absent and the disabled behavior is directly evidenced.
- `unavailable` is terminal only with a visible native-only boundary and no unsupported Web activation.
- Browser-equivalent capabilities require their exact fallback, permission, offline, and provider boundaries; source files alone are insufficient.
